**FXseek 媒体库 1.0.0** —— 一个自包含的 macOS 本地多模态素材库：用自然语言、自己的声音、或一张参考图，找你硬盘里的图片 / 视频 / 音频 / 文档。检索、打标、转写全部在本机完成，素材不出网。

## 这个版本能做什么

- 🔍 **文字搜画面**：不只搜文件名，向量检索理解「夕阳下的水面」「有气球的画面」这类画面内容，再做精排
- 🎙 **语音检索**：按住说话即搜；**哼一段旋律**则走声学指纹（Chromaprint）
- 🖼 **以图搜图 / 以音搜素材**：给一张图或一段音频找相似素材，命中视频时封面就是**命中的那一帧**
- 🗂 **30+ 格式**：图片 8 种 / 视频 8 种 / 音频 8 种，PDF、Office、WPS、纯文本、压缩包清单等文档
- 🎬 **不只是找**：缩略图墙与列表视图、内置播放器、音频**歌词页**（可一键转写）、搜索历史、回收站
- ✨ **漫步时光**：一键进入"回忆长廊"——只留图片与视频，按列交错缓缓滚动，点一下让某张优雅淡出
- 🤖 **接给本机 AI Agent**：内置 MCP server，DSH / Codex / Claude Code 等 6 个 Agent 一键检测与配置
- 🌗 中英双语、深浅色主题（可跟随时间）、索引源管理、本地 HTTP API

## 安装

1. 下载下面的 `FXseek-1.0.0.dmg`
2. **先删掉旧版**：`/Applications/FXseek.app`（直接覆盖会留旧文件）
3. 打开 dmg，把 `FXseek.app` 拖进「应用程序」
4. 首次启动会**自动下载内置模型（约 1.8 GB）**，默认国内镜像、失败自动换官方源，带进度与剩余时间
5. 应用未做 Apple 开发者签名，首次打开若被拦，请**右键 → 打开**

**要求**：Apple Silicon（M 系列）+ macOS 13 或更高。已在 Apple M4 上验证。
