# 运行时与二进制：怎么把仓库变成能构建的状态

仓库**只放源码**。要构建出可运行的 `.app` / `.dmg`，你需要在仓库根目录准备好三样东西：
`venv/`、`bin/`、`model/`（三者都被 `.gitignore` 忽略，见 [../.gitignore](../.gitignore)）。
下面是从零准备的完整做法（macOS / Apple Silicon）。

---

## 1. `venv/cpython-3.11/` —— 自包含 Python 运行时

应用不依赖用户机器上的 Python，构建时会把整个运行时拷进 `.app`，所以必须是
**可重定位的独立 CPython**（不要用 `python.org` 的 framework 版，也别用 Homebrew 的）。

```bash
# ① 取 python-build-standalone（astral-sh）的 macOS arm64 版
#    https://github.com/astral-sh/python-build-standalone/releases
#    下载 cpython-3.11.*-aarch64-apple-darwin-install_only.tar.gz 后：
mkdir -p venv && tar -xzf cpython-3.11.*-aarch64-apple-darwin-install_only.tar.gz -C venv
mv venv/python venv/cpython-3.11        # 目录名必须正好是 cpython-3.11

# ② 装依赖（版本以 requirements.txt 为准）
./venv/cpython-3.11/bin/python3.11 -m pip install -r requirements.txt
```

> ⚠️ 两个坑（都真实踩过）：
> 1. **别随手删 site-packages 里的包来"瘦身"**。只删代码却留下 `*.dist-info` 元数据时，
>    `pip install` 会说 "Requirement already satisfied" 而拒绝重装，问题会被掩盖很久
>    （本项目就因此让 PDF 文本提取静默降级了一版）。改瘦身列表前先跑
>    `./venv/cpython-3.11/bin/python3.11 tools/audit_deps.py`。
> 2. 装回来要加 `--force-reinstall --no-deps`，否则会被上面的元数据骗过去。

## 2. `bin/` —— ffmpeg / ffprobe / fpcalc 及其 dylib

```bash
mkdir -p bin/lib
# ffmpeg / ffprobe：用官方静态构建，或 Homebrew 装了再把依赖 dylib 一起搬进来
brew install ffmpeg chromaprint
cp "$(brew --prefix)/bin/fpcalc" bin/
# 关键：把 dylib 收进 bin/lib，并把可执行文件的依赖路径改写成 @loader_path/lib/xxx.dylib，
# 这样整个 .app 换台机器也不会因为找不到 /opt/homebrew 而起不来。
#   otool -L bin/ffmpeg          # 看它依赖什么
#   cp <dylib> bin/lib/          # 逐个搬
#   install_name_tool -change <原路径> @loader_path/lib/<名字> bin/ffmpeg
#   codesign --force --sign - bin/ffmpeg   # 改过 Mach-O 之后必须重新签名
```
最终结构：`bin/{ffmpeg,ffprobe,fpcalc}` + `bin/lib/*.dylib`（本项目约 20 个，37 MB）。

> 这些是第三方二进制（FFmpeg 为 GPL/LGPL、Chromaprint 为 LGPL），
> **不随仓库分发**，分发打包产物前请阅读 [../THIRD-PARTY.md](../THIRD-PARTY.md)。

## 3. `model/` —— 内置多模态模型（约 1.8 GB）

**通常不用手动准备**：用户第一次打开应用时，`model_dl.py` 会自动下载
（默认走国内镜像 `hf-mirror.com`，失败自动换 `huggingface.co`，带断点重试与进度条）。

需要预置（离线打包 / CI）时：

```bash
# 模型仓库：ewin-reg/WeMM-Embedding-2B-Apple-Silicon-MLX
export HF_ENDPOINT=https://hf-mirror.com
./venv/cpython-3.11/bin/python3.11 - <<'PY'
from huggingface_hub import snapshot_download
snapshot_download("ewin-reg/WeMM-Embedding-2B-Apple-Silicon-MLX", local_dir="model")
PY
```
也可以用环境变量 `FXSEEK_MODEL_DIR=/path/to/model` 指向任意位置（优先级最高）。

> 商用前请核对模型自身的许可 —— **代码许可不覆盖模型许可**。

## 4. 验证环境齐了

```bash
./venv/cpython-3.11/bin/python3.11 tools/audit_deps.py      # 依赖体检（业务 + 三方 + 空壳元数据）
./venv/cpython-3.11/bin/python3.11 app.py --port 8231       # 起服务，浏览器打开 http://127.0.0.1:8231
bash tools/build_app.sh --dmg                               # 出 .app + .dmg
hdiutil verify dist/FXseek-1.0.0.dmg                        # 必须打印 VALID
```
