装不上通常是这台设备还没登记。把 UDID 发给开发者，重新出一次包就能装了。
UDID 是一串 40 位的字母数字，不是序列号。

Install failures usually mean this device isn't registered yet. Send your UDID to the developer and the next build will work. It's a 40-character string — not the serial number.

1用 Mac 最省事Easiest — on a Mac
  1. 数据线连上 iPhone，打开 访达（Finder）
  2. 左侧选中你的设备
  3. 点设备名下方那行小字，多点几次，会依次切换：容量 → 电话号码 → UDID
  4. 看到 UDID 后右键 → 拷贝，粘到下面
  1. Connect the iPhone and open Finder
  2. Select your device in the sidebar
  3. Click the small line under the device name repeatedly — it cycles: capacity → phone number → UDID
  4. Right-click → Copy the UDID, then paste it below
2Windows 用 iTunesOn Windows — iTunes
  1. 装 iTunes，数据线连上 iPhone
  2. 进入设备 → 摘要 页
  3. 在「序列号」那行上点一下，会切成 UDID
  4. 右键 → 拷贝
  1. Install iTunes and connect the iPhone
  2. Go to the device → Summary
  3. Click the "Serial Number" line — it switches to UDID
  4. Right-click → Copy
