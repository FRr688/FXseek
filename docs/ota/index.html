装不上？按这个顺序来

Can't install? Try these in order

  1. 用 Safari 打开本页。微信 / QQ 内置浏览器不支持安装，右上角选「在 Safari 中打开」。
  2. Open this page in Safari. In-app browsers (WeChat, QQ) can't install apps — use "Open in Safari".
  3. 点上面的按钮，弹窗选 「安装」，然后回主屏幕等图标出现（约 1~3 分钟）。
  4. Tap the button, choose Install, then wait on the Home Screen for the icon (1–3 min).
  5. 图标出现后打不开（灰的 / 点了没反应）→ 说明这台设备还没登记，把 UDID 发给开发者重新出包。见下方「我的 UDID」。
  6. Icon appears but won't open (greyed out) → this device isn't registered yet. Send your UDID to the developer. See "My UDID" below.
  7. 下载中途断了 → 删掉图标，回本页重来。装到一半的包不会自动续。
  8. Download interrupted → delete the icon and start again. Partial downloads don't resume.
